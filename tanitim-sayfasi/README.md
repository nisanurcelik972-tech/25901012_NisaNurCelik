# Kişisel Tanıtım Sayfası

**Ad Soyad:** Nisa Nur Çelik
**Öğrenci Numarası:** 25901012
**Program:** Bilgi Güvenliği Teknolojisi

## Proje nedir?
Bu proje, BGY207 Web Tasarımı dersi için hazırladığım tek sayfalık kişisel tanıtım sitesidir. Sayfada Hakkımda, Eğitim ve Beceriler ve İletişim bölümleri; HTML ile yapı, CSS ile biçim ve duyarlı düzen, JavaScript ile form doğrulama ve koyu/açık tema düğmesi bulunur.

## Nasıl açılır?
`tanitim-sayfasi` klasöründeki `index.html` dosyasına çift tıklayarak tarayıcıda açın. Sunucu veya kurulum gerekmez.
